# 双语与中文排版

网站界面支持 **English** 和 **简体中文**。文章不翻译，Notion 里写的是什么就显示什么；
界面文字、首页文案、日期格式、字体随语言切换。

## 语言怎么决定

| 顺序 | 来源 | 说明 |
| --- | --- | --- |
| 1 | `?lang=zh-CN` / `?lang=en` | 显式指定；同时写入 cookie |
| 2 | `lang` cookie | 一年有效，`SameSite=Lax`；点击 `EN / 中文` 就是带 `?lang` 的普通链接 |
| 3 | `Accept-Language` | 第一次访问时按浏览器语言（支持 q 值；`zh`、`zh-TW`、`zh-Hans` 都归到简体中文） |
| 4 | `en` | 默认 |

- 实现：`src/shared/i18n.ts`（纯函数，有单元测试）+ `src/middleware.ts`（写 `Astro.locals.locale`、cookie、`Content-Language`、`Vary`）。
- 默认语言（英文）用干净的 URL；中文页面的链接都带 `?lang=zh-CN`，所以中文页面可以被分享、被搜索引擎收录。
  `sitemap.xml` 为每个页面列出两种语言（`hreflang="en" / "zh-CN" / "x-default"`），每页 `<head>` 里也有对应的 `alternate`。
- `/api/site` 只认 `?lang`（不看 cookie），保证同一个 URL 永远返回同一种语言。RSS 与 robots.txt 只有英文。
- 在首页切换语言：脚本把当前滚动位置存进 `sessionStorage`，新页面直接回到原位，不重播开场动画。

## 文字放在哪里

| 内容 | 位置 |
| --- | --- |
| 导航、区块标题、按钮、分页、搜索提示、404 等界面文字 | `src/ui/i18n.ts`（`messages(locale)`；测试保证两种语言的键完全一致） |
| 首页引言、facts、标语、默认简介 | `src/content/site.ts` 的 `copy.en` / `copy['zh-CN']` |
| 站点简介（meta description）与首页引言的覆盖值 | 后台 Settings：`site_about` / `site_intro`（英文），`site_about_zh` / `site_intro_zh`（中文） |

中文覆盖值留空时使用内置中文文案，**不会回退到英文**——中文页面上不会突然出现一段英文引言。

文章标题、摘要、标签按内容自动标注 `lang`（`contentLang`：含汉字即为 `zh`），所以英文界面上的中文标题仍按中文排版，反之亦然。

## 字体：让中文和英文是同一种声音

原设计的标志是 **Archivo 62% 宽、800 字重、全大写**——瑞士网格风格的窄体粗黑。
直接把同样的 CSS 用在中文上，浏览器会退回系统黑体的常规宽度：方正、偏细、字面比英文大写字母高一截，
标题在两种语言之间来回切换时，整页的“音色”就断了。

### 显示字体：Red Room Display SC

| | 英文 | 中文 |
| --- | --- | --- |
| 字形骨架 | Archivo（新怪诞体） | Noto Sans SC / 思源黑体（同属无衬线黑体） |
| 宽度 | `font-stretch: 62%` | 字形**压缩到 82%**（长体） |
| 字重 | 800 | **900（Black）**——压窄后竖笔会变细，Black 补回与 Archivo 800 相同的灰度 |
| 字高 | 大写字母约占 em 的 70% | `size-adjust: 88%`，让汉字与大写字母一样高 |
| 大写 | `text-transform: uppercase` | 汉字没有大小写，不受影响 |

所以 `NOTION 写作工作流 2026` 这样的中英混排标题可以共用一条基线、一样的高度和粗细，不需要给中文单独设字号。

**为什么要生成一个字体文件，而不是用 CSS 压缩？**
`transform: scaleX()` 只改变绘制，不改变排版盒子：标题后面会留出空白、换行位置是按原宽度算的。
目前也没有带宽度轴的中文字体。把轮廓离线压缩一次，浏览器拿到的就是一款“本来就窄”的普通字体，
换行、选中、混排都和英文设计一样工作。

**生成方式**（`scripts/fonts/build-display-sc.py`，只在调整参数时需要重新运行）：

```bash
npm install                                   # 带来 devDependency @fontsource-variable/noto-sans-sc
pip install fonttools brotli                  # 或 pip install --target /tmp/pylib … 再加 PYTHONPATH=/tmp/pylib
python3 scripts/fonts/build-display-sc.py     # 输出到 public/fonts/display-sc/
```

脚本沿用 fontsource 的 unicode-range 切片（96 片，共约 2.3 MB），浏览器只下载页面上真正出现的汉字所在的切片；
emoji 等 U+1F000 以上的码位不收录，交给系统字体。字体按 SIL OFL 1.1 改名为 “Red Room Display SC”，许可证在同一目录。

实测（中文首页有 8 篇中英文章时）：中文首页下载 11 片约 328 KB，中文文章页 6 片约 174 KB，没有中文的英文页面 0 字节。
样式表 `display-sc.css` 以非阻塞方式加载（`media="print"` + `onload`，带 `<noscript>`），字体用 `font-display: swap`，不会拖慢首屏。

### 正文：系统黑体

正文（Archivo 400–650）配的是系统黑体：苹方 / 冬青黑体 / 微软雅黑 / Noto Sans CJK（`--cjk`）。
它们与 Archivo 同属无衬线黑体，屏幕上已经调校得很好，并且**零下载**——
一篇长文用到的汉字会分布在几十个切片里，正文用 webfont 意味着每篇文章要下载 1 MB 以上。

字体栈总是**拉丁字体在前**（`'Archivo Variable', …, var(--cjk)`），所以混排时字母和数字始终是 Archivo，汉字才落到中文字体。

### 哪些元素用显示字体

`src/ui/styles/base.css` 里有一张列表：所有用了 `font-stretch: 62%` 的元素都必须在里面
（`.count` `.bar .brand` `.sec` `.row .t` `.mail` `.site-brand` `.prose h1` `.page-head h1` `.admin h1` `.admin-sec`）。
`tests/i18n.test.mjs` 会扫描所有样式表：新增窄体元素却忘了加进列表，测试会失败。

### 其他中文细节（全部在 `src/ui/styles/cjk.css`）

规则都写成 `:lang(zh)`，同时作用于中文界面和英文界面里的中文内容。

- **行距**：汉字占满整个 em 框，英文大写只占约 70%。英文标题的 .82–1 行距会让换行的中文上下相碰，多行元素加大行距（列表标题 1.12、文章标题 1.1、引言 1.32、正文 1.9）。
- **字距**：英文小标签的大字距在中文里像字与字之间的空洞，统一收小；导航、元信息保留少量字距。
- **引言**：中文字面更“满”，字号比英文略小（`clamp(1.7rem, 3.7vw, 3.7rem)`）。逐词点亮动画用 `Intl.Segmenter` 按词切分，标点粘在前一个词上，不会单独亮起一个逗号。
- **强调**：中文没有斜体，机器倾斜的黑体很难看。文章里的 *斜体* 在中文中显示为**着重号**（字下加点）。
- **正文**：两端对齐、`line-break: strict`（标点避头尾），支持的浏览器会自动在中英文之间加空隙（`text-autospace`）。
- **日期**：中文为 `2026年10月27日`，带时间时 `2026年10月27日 21:30`；显示的是作者在 Notion 里写下的时间，不做时区换算。

## 新增一种语言

1. `src/shared/i18n.ts`：把语言加进 `LOCALES`，并在 `parseLocale` 里写好匹配规则。
2. `src/ui/i18n.ts`：补一份字典（测试会检查键是否齐全）。
3. `src/content/site.ts`：补一份 `copy`。
4. 如需后台覆盖：`contracts.ts` 的 `SettingKey` 与 `services/settings.ts` 的 `COPY_KEYS`。
5. 非拉丁文字的标题如果要配窄体，参照 `build-display-sc.py` 生成对应的显示字体，并在 `--display` 字体栈里加上。
