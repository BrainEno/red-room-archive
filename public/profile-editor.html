Offline site profile editor

This tool only edits a local file in your browser. It does not log you in, save to the website, or make live changes. Do not enter passwords, tokens or private information: these fields become public when you deploy.

Import an existing profile or fill the fields below. Blank fields use site defaults. Export site-profile.json, put it in the repository root, and rebuild on Netlify or Cloudflare. Keep a backup of the file. Notion credentials must be configured separately.
